# Andromeda Knowledge Base

Status: local-only content source
Owner: SIRINXDev
Series: Andromeda Marketing Tips

This file is the durable topic bank for 100 short educational episodes. Each
topic should become one 6-8 second clip unless a later spec expands it.

Safety default: educational content only. Direct offers must use
`campaign-offers.md`.
