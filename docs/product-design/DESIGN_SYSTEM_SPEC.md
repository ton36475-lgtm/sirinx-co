# Design System Spec

Status: LOCAL ONLY

## Foundations

- Typography
- Color tokens
- Spacing tokens
- Radius tokens
- Shadow/elevation tokens
- Motion tokens
- Icon policy

## Components

- App shell
- Navigation
- Dashboard card
- Data table
- Form controls
- Approval packet panel
- Evidence card
- Timeline entry
- Product design artifact card

## Rules

- No prototype visual style becomes production style without design review.
- Text must fit at mobile and desktop sizes.
- Components must map to acceptance criteria when they are part of a deliverable.
