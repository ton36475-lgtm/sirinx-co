# 30-Day Launch Plan

Status: launch sprint.

## Week 1: Market And Proof

- choose one niche
- create one offer
- create 10 portfolio mockups
- create one landing page
- create LINE OA / DM flow
- create CRM pipeline

Output:

- AI Local Promo Pack.
- 10 portfolio samples.
- 7-day content calendar.
- 100 leads.

## Week 2: Content Engine

- publish daily
- create 3-5 short videos or prompt packs
- create before/after posts
- begin opt-in outreach

Output:

- 20-30 posts.
- 100-150 new leads.
- 20-40 conversations.

## Week 3: Sales Sprint

- contact 30-50 leads/day within policy
- send one clear offer
- follow up in three rounds
- close entry package
- deliver fast

Output:

- 3-5 paying clients.
- first reviews.
- before/after case study.

## Week 4: Proof And Scale

- convert client work into case studies
- create one prompt pack
- open monthly offer
- create KPI dashboard

Output:

- 3-5 case studies.
- one prompt pack.
- one monthly offer.
- KPI report.
