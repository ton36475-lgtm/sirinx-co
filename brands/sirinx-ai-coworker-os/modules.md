# SIRINX AI Co-worker OS Modules

Status: canonical module map
Source: 2026-06-07 image intake

## 1. AI Co-worker Foundation

Goal: teach the business how to install AI as a workflow system.

Capabilities:

- Define what an AI co-worker is.
- Identify where chatbot-style AI is insufficient.
- Design workflows for repetitive work.
- Delegate tasks to AI with clear scope.
- Create reusable context packs.
- Create the first AI team roles.

Core artifacts:

- Business context pack
- Co-worker role cards
- Task routing map
- Approval checklist
- Local evidence folder

## 2. Marketing Co-worker

Goal: help plan and execute marketing work with structure.

Capabilities:

- STP
- Persona
- Funnel
- Customer journey
- Campaign design
- Content strategy
- Content calendar
- Ad copy and caption drafts
- Landing page copy drafts
- Competitor analysis
- Marketing brief

Blocked without approval:

- Auto-posting
- Paid ads changes
- CRM mutation
- Customer data upload

## 3. Admin Co-worker

Goal: reduce repetitive documentation and reporting work.

Capabilities:

- Meeting summary
- Follow-up list
- SOP draft
- Report draft
- Executive summary
- Weekly report
- Dashboard update draft
- Data summary
- Project summary
- Document organization

Core artifacts:

- Meeting notes template
- SOP template
- Report template
- Admin task checklist

## 4. Workflow Design Co-worker

Goal: convert scattered tasks into repeatable systems.

Framework: 4D

- Delegation: decide what AI can do.
- Description: describe tasks, context, constraints, and outputs.
- Discernment: classify risk, quality, and human-review needs.
- Diligence: verify output, keep evidence, and improve the workflow.

Core artifacts:

- Workflow map
- Task packet
- Owner matrix
- Risk matrix
- Evidence packet

## 5. Finance Co-worker

Goal: support financial visibility and executive review.

Capabilities:

- Cash flow summary
- Budget vs actual
- Forecast draft
- Financial analysis draft
- Budget planning draft
- Financial dashboard draft
- Cost analysis
- Monthly review
- Executive brief

Safety boundary:

- Informational support only.
- No investment, accounting, tax, or legal advice.
- No external banking/accounting connection without separate approval.
- Use mock/sample data in local prototypes.

## 6. Predictive AI Co-worker

Goal: help leaders think ahead with signals and scenarios.

Capabilities:

- Generative AI support
- Predictive signals
- Prescriptive suggestions
- Timing analysis
- Decision-support summaries

Safety boundary:

- Predictions must be labeled as scenario support.
- No unsupported certainty claims.
- Decision making stays with the human owner.

## Bonus. Video Co-worker

Goal: turn business knowledge into repeatable video assets.

Pipeline:

```text
Prompt -> Script -> Storyboard -> Subtitle -> Motion -> Preview -> Render
```

Input formats:

- Website to video
- PDF to video
- Blog to video
- Presentation to video

Capabilities:

- Script
- Storyboard
- Voice over
- Subtitle
- Motion graphic
- Product demo
- Social video / explainer
- Preview and render prep

Blocked without approval:

- Provider render calls
- Avatar generation
- TTS provider calls
- Live publishing
