# UI to Spec Pipeline

Status: LOCAL ONLY

## Pipeline

```text
Screenshot or idea
-> UI inventory
-> User goal
-> Data model
-> State model
-> Acceptance criteria
-> Test checklist
-> Evidence requirements
-> Approval packet
```

## Annotation Rule

When a UI area is selected or annotated, Codex must change only the scoped area
unless the spec explicitly expands the scope.

## Output Rule

All UI changes must produce:

- changed screen list
- changed components
- changed states
- changed tests
- changed evidence needs
