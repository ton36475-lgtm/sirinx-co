# Reference Landing Patterns for CHOKMA

เอกสารนี้สรุปข้อค้นพบจากหน้าอ้างอิงที่ผู้ใช้ส่งมา และจากหน้าสมัครจริงของ CHOKMA เพื่อใช้เป็นฐานในการปรับ Landing Page ให้เรียบง่าย ตรงประเด็น และปิดการสมัครได้เร็วขึ้น

| แหล่งอ้างอิง | ข้อค้นพบสำคัญ | สิ่งที่ควรนำมาปรับใช้กับ CHOKMA |
| --- | --- | --- |
| `https://hi99s.co/sms/` | หน้าแคมเปญใช้ภาพใหญ่ชิ้นเดียว สารหลักชัดมาก เห็นข้อเสนอทันที และแทบไม่มีทางเลือกอื่นมารบกวน | ทำโครงหน้าแบบแคมเปญ เน้นข้อความหลัก 1 ประเด็น ข้อเสนอ 2-3 ข้อ และ CTA เด่นเหนือ fold แรก |
| `https://www.hi99.pro/` | หน้าแรกใช้ภาษาเรียบง่าย เน้นสมัครง่าย ฝากถอนเร็ว เว็บตรง ปุ่มสมัครชัด และเรียงความน่าเชื่อถือเป็นช่วงสั้น ๆ | ลดความซับซ้อนของ copy ใน Home ให้สแกนจบเร็ว เพิ่ม trust row สั้น ๆ และทำ CTA ให้เด่นกว่า section อื่น |
| `https://โชคมา.net/auth/registration?af=u2vZe3xLLiJ7` | หน้าปลายทางสมัครจริงเป็น flow สั้นมาก เริ่มจากกรอกเบอร์มือถือ มีเพียงปุ่มถัดไปและปุ่มมีไอดีแล้ว โทนแบรนด์เป็นน้ำเงิน-ทอง | หน้า Landing ต้องพาผู้ใช้ไปสู่การกรอกเบอร์ให้เร็วที่สุด ใช้ CTA ทุกจุดชี้ไปลิงก์นี้โดยตรง และใช้ภาษาที่เตรียมผู้ใช้เข้าสู่ step แรกของการสมัคร |

สรุปเชิงออกแบบคือ หน้าใหม่ของ CHOKMA ควรลดโครงสร้างแบบข้อมูลหนาแน่นลง และเปลี่ยนเป็นหน้าแนว **single-goal conversion page** ที่มีเพียงสามชั้นหลัก ได้แก่ Hero ที่บอกข้อเสนอทันที, แถบความน่าเชื่อถือแบบสั้น, และส่วนขยายความสำหรับผู้ที่ต้องการอ่านเพิ่มก่อนกดสมัคร

ในเชิง conversion flow หน้าอ้างอิงและหน้าสมัครจริงชี้ชัดว่าปลายทางของผู้ใช้คือการกรอกเบอร์มือถือ ไม่ใช่การอ่านข้อมูลจำนวนมาก ดังนั้น CTA บนหน้า Landing ของ CHOKMA ควรใช้ภาษาที่พาผู้ใช้ไปยังขั้นตอนนี้โดยตรง เช่น การเริ่มสมัคร, รับสิทธิ์, หรือเข้าสู่ขั้นตอนยืนยันเบอร์ โดยต้องลดจำนวนทางเลือกคู่แข่งบนหน้าให้เหลือน้อยที่สุด

ในเชิงแบรนด์ หน้าสมัครจริงของ CHOKMA ใช้โทนสีน้ำเงิน-ทองและองค์ประกอบกรอบทองที่ชัดเจน จึงควรทำหน้า Landing ให้เชื่อมภาพจำเดียวกัน เพื่อไม่ให้ผู้ใช้รู้สึกว่าหลุดจาก flow เมื่อกด CTA ไปยังหน้าสมัครจริง
