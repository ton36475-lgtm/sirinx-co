## Rollback

1. `wrangler pages deployment list --project-name=sirinx-co` to get the previous
   Production id (`086ac283-6761-4a73-8ec7-56d9cccffb98` at time of writing).
2. In the Cloudflare dashboard → Pages → `sirinx-co` → Deployments → select that
   deployment → "Rollback to this deployment".
3. Re-check `https://www.sirinx.co/` and `/projects/`.

Because deployment is an immutable snapshot, no source revert is needed for a
rollback; a later redeploy from a fixed commit supersedes it.
