# Idea to Prototype Runbook

Status: LOCAL ONLY

## Step 1 - Intake

Capture the operator's idea without expanding scope.

Output:

```text
problem
target user
desired outcome
non-goals
risk notes
proof status
```

## Step 2 - Brief

Write a product brief that can be reviewed before any UI or code work.

## Step 3 - Flow

Define the smallest useful user flow. Avoid extra screens.

## Step 4 - Wireframe

Use text wireframes first. Visual generation comes after the flow is stable.

## Step 5 - Prototype

Prototype is allowed only as local preview. It is not production.

## Step 6 - Handoff

Create implementation tasks only after the design artifact passes review.

## Stop Point

```text
CODEX PRODUCT DESIGN READY - WAITING FOR APPROVE_IMPLEMENTATION
```
