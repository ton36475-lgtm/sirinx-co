# Memory Is Not Truth

Memory can guide search, but it cannot promote a claim by itself.

## Allowed Language

- "This note claims..."
- "This local artifact shows..."
- "This hash matches..."
- "This commit records..."
- "This external record verifies..."

## Blocked Language

- "Proven" without an evidence chain.
- "Done" without local artifact or test evidence.
- "Production ready" from a prototype.
- "Verified on GitHub" from a local-only file.
