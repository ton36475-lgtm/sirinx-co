# Codex Product Design Layer

Status: LOCAL ONLY - WAITING FOR PART 8 APPROVAL

## Purpose

Codex is the engineering worker, but product work starts before code. This layer
turns ideas into a brief, flow, screen model, design system, prototype, spec,
task pack, implementation plan, evidence packet, and approval gate.

## Pipeline

```text
Idea
-> Product Brief
-> User Flow
-> Screen List
-> Wireframe
-> Design Tokens and Components
-> Prototype
-> Specification Pack
-> API/Data Draft
-> Implementation Tasks
-> Local Implementation
-> Test and Verification
-> Evidence Packet
-> Approval Gate
```

## Rules

- Spec before code.
- Prototype is not production.
- Use mock/sample data only.
- Do not use real secrets.
- Do not use real customer data.
- Every product artifact has a proof status.
- Every implementation task links back to a spec and acceptance criteria.
