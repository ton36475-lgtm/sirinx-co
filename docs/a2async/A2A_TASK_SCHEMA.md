# A2A Task Schema

This schema is intentionally JSON-first so scripts can validate it using only
Python standard library tooling.

## Task Manifest Fields

```json
{
  "a2a_version": "ghostclaw-a2async-v2",
  "task_id": "A2A-YYYYMMDD-HHMMSS",
  "project": "ghostclaw",
  "from_agent": "kob-cli-opus",
  "to_agent": "codex-5-6",
  "task_type": "multi_repo_integration",
  "mode": "full_auto",
  "repo_path": "~/SIRINXDev/sirinx-agent-native-os",
  "goal": "Validate A2A registry and prepare integration plan",
  "model_route": {},
  "scope": {
    "allowed_paths": [],
    "blocked_paths": []
  },
  "policy": {},
  "broker_decision": {
    "required": true,
    "decision": "",
    "artifact_path": "",
    "required_gate": ""
  },
  "executor_lease": {
    "required": false,
    "lease_id": "",
    "lane": "",
    "executor": ""
  },
  "messages": [],
  "artifacts": [],
  "status": {
    "state": "queued",
    "reason": ""
  },
  "created_at": "ISO-8601",
  "updated_at": "ISO-8601"
}
```

## Message

Messages are short planning or execution notes exchanged by agents. They should
not contain secrets, browser cookies, raw credentials, or full `.env` lines.

## Artifact

Artifacts are file references, reports, summaries, patches, validation logs, or
command plans. Store artifact contents under runtime folders and reference them
from the manifest.

## Broker Decision

Every task that targets a tool, repo, connector, provider, or executor should
reference a Codex command broker artifact. The broker decision is created by
`scripts/a2a/a2a_command_broker.py` and uses
`policies/codex_command_broker.json`.

Allowed decision values are:

- `auto_allow_dry_run`
- `requires_executor_lease`
- `policy_controlled_registry_allow`
- `blocked_first_phase`
- `blocked`

Tasks with `blocked`, missing, or stale broker decisions must not execute.

## Executor Lease

Tasks routed to `opencode` or `agy-antigravity2` must include or reference an
executor lease. The lease defines the exact lane, allowed paths, validation
commands, and expiry. Missing leases block scoped executor mutation.

For Manus handoff tasks, use `task_type: manus_artifact_review` and reference a
`manus_artifact_metadata` artifact generated by
`scripts/a2a/a2a_manus_adapter.py`. The task should contain only metadata and a
summary; Codex must inspect the exported file separately before importing any
content into the repo.

## Blocked Paths

Default blocked paths include `.env`, `.env.*`, private keys, credentials,
browser profiles, token stores, and cloud config files.
