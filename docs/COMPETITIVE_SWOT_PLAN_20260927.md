# SWOT และแผนต่อยอด SEO/AEO/GEO — www.sirinx.co

วันที่ 2026-09-27 · ทุกข้อข้างล่างวัดจากเว็บจริงหรืออ้างอิงแหล่งที่เปิดตรวจได้ ไม่มีการคาดเดา

## 0. ข้อจำกัดที่ต้องบอกก่อน — ตรวจอันดับจริงไม่ได้

คำขอเดิมคือ "ศึกษาแบรนด์ที่มีอันดับ 1 ในทุกลีเซอร์ไรด์" — **ผมยืนยันส่วนนี้ไม่ได้** และไม่จะเดาแทน:

- ไม่มี Search Console / GA4 ที่เข้าถึงได้ → วัด impression, position, CTR จริงไม่ได้
- ไม่มีเครื่องมือ SERP (Ahrefs/Semrush) → วัดอันดับคู่แข่งไม่ได้
- การค้นอัตโนมัติถูกบล็อก: DuckDuckGo มี anti-bot, Bing ต้องมี API key, Mojeek มี captcha, browser bridge ใช้ไม่ได้

**สิ่งที่ทำแทนได้** คือวัดสิ่งที่วัดได้จริง: โครงสร้างเว็บที่ deploy แล้ว, schema จริง, สิ่งที่คู่แข่งทำและไม่ทำ, และหลักฐานว่าอะไรได้ผลใน AEO/GEO จากงานวิจัยที่มี URL

## 3. ภูมิทัศน์คู่แข่ง (ตรวจจริง 14 เว็บ)

### 3.1 เครือข่าย doorway ที่ต้องระวัง

`sunc.co.th` และ `rtdai.co.th` **ไม่ใช่เว็บโซลาร์** — หน้าแรกเป็นเว็บเช่าเต็นท์และไดเรกทอรีงานอีเวนต์ (Inaka68 / EventWork) แต่มีโฟลเดอร์ `/solarworks/` ซ่อนอยู่:

- 17 + 16 = **33 หน้า** (ตรวจแล้ว ยังไม่ exhaustive)
- ใช้เบอร์โทรเดียวกัน `095-5471465`
- **ไม่มี JSON-LD เลย**
- **ไม่ปรากฏใน sitemap.xml** ของทั้งสองโดเมน
- control test: slug มั่วคืน 404 จริง (ไม่ใช่ soft-404)

**อ่านให้ถูก**: การซ่อนหน้าไว้นอก sitemap และไม่มี schema แปลว่าคู่แข่งคนนี้**ทำ SEO ไม่ถูกต้องเช่นกัน** — เป็นการเก็บ keyword ไม่ใช่การแข่งขันที่ผ่านมาตรฐาน Google แต่ก็เป็นความเสี่ยงเพราะอาจถูกจัดการเป็น doorway page ในอนาคต

### 3.2 SIRINX แข็งกว่าตลาดเรื่องอะไร

worker ตรวจ 14 โดเมนแล้วสรุป: 77 location page พร้อม `FAQPage`/`HowTo`/`Article` schema **แข็งกว่าเกือบทั้งตลาด** — คู่แข่งส่วนใหญ่ไม่มีแม้แต่ JSON-LD

### 3.3 ช่องว่างที่ยังไม่มีใครทำ

- **Sole commercial ระดับโรงงาน**: CapSolar ระบุชัด 22–30 ล้านบาท/MWp
- **ไม่มีใครให้ราคาต่อตารางเมตรสำหรับ SME** — ช่องว่างของ SIRINX
- **ไม่มีใครทำ 77 location page พร้อมหลักฐานงานจริง** — SIRINX มี `/projects/ruenphae-royal-park` แต่ไม่ถูกลิงก์จากหน้าจังหวัด (ดู G-03)

## 5. อะไรที่ "ยังไม่มีหลักฐาน" — อย่าเพิ่งเชื่อ

งานวิจัยได้ระบุชัด ผมถอดมาให้ตรง ๆ:

| คำกล่าว | สถานะ |
|---|---|
| "GEO รับประกันว่าจะถูกอ้างอิง" | **ไม่มีหลักฐาน** — natural experiment 2026 ให้ 1.82x แต่ placebo p=0.16 และ headline ของ vendor เกินจริงราว 3 เท่า |
| "ใส่ llms.txt แล้วจะถูก ChatGPT อ้างอิง" | **ไม่มีหลักฐานว่า AI search consumer อ่านไฟล์นี้** — วัดผลได้เฉพาะบริบท agentic/RAG |
| "schema markup คือตัวขับ AI citation" | **ผลน้อย** — งานวิจัย 2026 วัด JSON-LD ได้ผลเล็กน้อย ส่วน entity page แบบ llms.txt ได้ +29.6% |
| "อันดับ 1 ทุกลีเซอร์" | **ตรวจไม่ได้** — ไม่มี Search Console/GA4, SERP tools, และ search engine บล็อกการค้นอัตโนมัติ |

**ข้อสรุปที่สำคัญที่สุดจากงานวิจัย**: Google ระบุตรง ๆ ว่า AI Overviews / AI Mode **ไม่มีข้อกำหนดทางเทคนิคเพิ่มเติมจาก SEO ปกติ** แปลว่างานที่ต้องทำต่อไปไม่ใช่เพิ่มมิติเชิง AI แปลก ๆ แต่คือ **ทำ SEO พื้นฐานให้ครบและให้ machine อ่านได้** ซึ่งจุดที่เสียอยู่คือ G-01 ถึง G-04

## 6. แผนลงมือ เรียงตามผลกระทบต่อรายได้

ยังไม่ลงมือแก้จนกว่าจะได้รับอนุมัติ — แต่ละข้อระบุว่าวัดอะไรเพื่อพิสูจน์ว่าได้ผล

| # | งาน | เหตุผล | วัดผลได้ด้วย |
|---|---|---|---|
| 1 | **SSR หรือ prerender หน้า `/pricing/` `/projects/` `/assessment/` `/solar-carport/`** | machine อ่านไม่ออก — เป็นรายได้ที่หายไปตอนนี้ | ข้อความใน HTML ฝั่ง server > 0, H1 = 1 |
| 2 | **ลิงก์หน้า 77 จังหวัดจากหน้าแรก** | ลดความลึกจาก 2 คลิกเหลือ 1 | จำนวน link จาก `/` → province > 0 |
| 3 | **ใส่ลิงก์ funnel ในหน้าจังหวัด** (ประเมิน / ราคา / ผลงาน) | funnel ขาดตรงนี้ | ลิงก์ไป 3 หน้านี้ > 0 ในทุก province |
| 4 | **เพิ่มราคาต่อตารางเมตร + อธิบายภาษีแบบมีอ้างอิง** | ช่องว่างที่ไม่มีคู่แข่งทำ | ต้องมีตัวเลขจริง + แหล่งอ้างอิง |
| 5 | เพิ่ม H2/H3 ใน `/provinces/` | โครงสร้างแบนราบ | H2 > 0 |
| 6 | ย่อ meta description ให้ ≤160 | ถูกตัดในผลลัพธ์ | ความยาวทุกหน้า |
| 7 | เพิ่ม RSS/feed | ช่องทาง syndication | HTTP 200 |
| 8 | เผยแพร่ case study จากโครงการจริง | ยังมีแค่ 1 และไม่ถูกเชื่อม | มีลิงก์จากหน้าจังหวัด |

### สิ่งที่ควรทำแต่ต้องรอคุณตัดสิน

- ราคาที่จะประกาศ: ต้องมาจากใบเสนอราคาจริง ไม่ใช่ค่าประมาณที่ผมคำนวณ

- การเพิ่มรีวิว/case study: ต้องได้ consent จากลูกค้าจริง

## 7. สิ่งที่ยังทำไม่ได้และไม่ควรเดา

1. **ยืนยันอันดับจริงไม่ได้** — ต้องมี Search Console ก่อน
2. **วัดว่าถูก AI อ้างอิงจริงหรือไม่ไม่ได้** — search engine บล็อกการค้นอัตโนษา ต้องใช้ Search Console หรือเครื่องมือชำระเงิน
3. **จำนวน URL ทั้งเครือข่าย doorway** — ตรวจได้ 33 หน้า ยังไม่ exhaustive
4. **ช่องทาง YouTube / Facebook / Shopee / Google Business Profile** — ยังไม่ได้ตรวจเชิงปริมาณ
5. **ผลกระทบด้าน Core Web Vitals** — ยังไม่ได้วัดในเครื่องจริง

## ภาคผนวก: วิธีตรวจที่ใช้

ทุกตัวเลขในเอกสารนี้มาจากการรันจริง ไม่ใช่การอ่านโค้ด:

- crawl 77 หน้า province จริงจาก sitemap (4.5 วินาที)
- ตรวจ visible text ของหน้า SPA หลังตัด script/style
- control test ยืนยัน 404 ปกติ ก่อนเชื่อว่า `llms.txt` เป็นของจริง
- แยก "ตัวเลขราคา" ที่เจอเป็นตัวเลขจาก JS ที่ย่อ ออกให้ถูกต้อง
