# Product Review Gate

Status: LOCAL ONLY

## Required Before Implementation

- Product brief exists.
- User flow exists.
- Screen list exists.
- Acceptance criteria exist.
- Test checklist exists.
- Evidence requirements exist.
- Risk notes exist.
- Approval condition is explicit.

## Review Outcomes

| Outcome                           | Meaning                                             |
| --------------------------------- | --------------------------------------------------- |
| APPROVED_FOR_LOCAL_IMPLEMENTATION | Codex may implement locally                         |
| NEEDS_MORE_SPEC                   | Design artifact is incomplete                       |
| BLOCKED_BY_RISK                   | Security, data, legal, or approval risk blocks work |
| PROTOTYPE_ONLY                    | Output may be previewed but not productionized      |
