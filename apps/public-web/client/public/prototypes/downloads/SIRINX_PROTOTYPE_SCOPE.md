# SIRINX ecosystem prototype — scope and source map

**Date:** 9 October 2026 · **Artifact:** static HTML prototype and local mock API only.

## Existing experiences retained

- **`sirinx.org`** — the existing knowledge directory and its six regional groups / 77 province links remain on `/`; the proposal adds navigation to the expanded prototype, policy/evidence status, provenance, a 2D concept flow and a shared-back-office concept. No policy interpretation is made.
- **`sirinx.co`** — the existing dark navy/cyan/gold experience, hero imagery from the SIRINX site/source, section order, project claims, assessment fields, investment and FAQ remain on `/co.html`. The proposal adds a hub link and source/claim labels; it does not replace the live route.
- **Existing `.co` routes represented in the route map:** Home, Solar Carport, Solutions, Industries, Projects, Pricing/Investment, Strategy, Blog, Partner, About, Policy, Assessment and Contact. Dedicated local interactions now cover quote prerequisites, strategy review briefs, editorial filters, about/leadership review, intent routing and policy-state taxonomy; no unverified price, claim or contract is filled in.

## Proposed hosts — not live/resolved at inspection

- `ai.sirinx.co` — proposed enterprise AI/service intake and source-cited knowledge workflow.
- `ai.sirinx.org` — proposed AI knowledge, policy and evidence library.
- `cloud.sirinx.co` — proposed cloud/GPU service proposal. Any INET relationship, capacity, pricing, SLA or availability is unverified.
- `cloud.sirinx.org` — proposed neutral cloud/compute knowledge and policy library.

The four hosts are shown as named experiences inside `/prototypes/`; they are not DNS or production deployments.

## Proposal functions

- Source/route explorer and status filtering.
- Non-calculating Solar / BESS / EV / EMS assessment brief and pricing/investment input checklist; no ROI, quote or forecast result.
- Functional proposal previews for About, Strategy, Blog/video/speaking topics, contact intent routing and policy-state taxonomy.
- Partner, AI and cloud intake previews with no real submission.
- Evidence/provenance registry that distinguishes `WEBSITE CLAIM`, `PENDING`, `SCENARIO`, `STALE` and `OFFLINE`.
- CEO and staff branding proposal with opt-in consent scopes for name/photo/voice/video/quote/byline/credentials, synthetic image-rights register, expiry and withdrawal/update path; no real personal record or forced promotion.
- Shared-back-office concept with separated public knowledge, engineering, intake and consent roles; synthetic queue only.
- OpenAPI/Postman mock contracts and local loopback-only server with 12 synthetic routes; the hosted static preview stays fixture-only, and the local UI calls only its same-origin mock server.
- Original 2D clay-style SVG; optional on-demand Three.js 0.186.1 / Anime.js 4.5.0 rendering with static and reduced-motion fallback.
- Public GitHub file-tree/manifest inventory, migration-candidate catalog and reusable coding prompt pack.
- BESS addendum (15 October 2026): `/bess.html` is an additive `.co` service/assessment prototype; `/bess-knowledge.html` is an additive `.org` knowledge prototype. Both are `noindex,nofollow`; the Solar Carport hero and 77-province directory remain intact.
- `public/data/bess-master.json` is shared by both BESS pages and local mock API. Manufacturer-reported specifications and conflicts are explicitly labeled; assessment does not calculate sizing/ROI or create a lead.

## Sources and access limits

- Live pages were read read-only on 8–9 October 2026; see `SOURCE_AUDIT.md` for URLs and claim conflicts.
- `.org`, `.co`, `.co/assessment/`, DOE storage basics and the GSL candidate product page were rechecked read-only on 15 October 2026; see the BESS addendum in `SOURCE_AUDIT.md` and `BESS_IMPLEMENTATION.md`.
- Public GitHub API returned 24 repositories and 64,683 default-branch path entries. One tree (`ghost-claw-os`) is truncated and dominated by vendored dependencies. 125 package/build manifest and presence records were fetched; a path inventory is not a full reading of every code file.
- Private repositories are not visible to the unauthenticated public listing. The user asked to use two Drive folders, but no Google Workspace account is currently authorized to the task; the user has been asked to choose an account. No Drive content is included until that permission is resolved.
- The earlier GitHub repo `sirinx-co` main contains the current accessible `.co` source family; the `feat/sirinx-org-clay-anime` branch is a prototype branch, not verified production. No deployment mapping was established for `.org`.

## Exclusions and safety

No source repository, branch, live website, DNS, Cloudflare configuration, database, API, CRM, email, payment, GPU account, energy device or production system was edited or connected. No migration was executed. No real ROI, energy yield, telemetry, GPU metrics, official policy eligibility, contract, SLA, testimonial or project result was fabricated. The user-provided reference images were not embedded because their reuse rights were not verified; the concept scene is original SVG/geometry.
